# Machine Learning Holdout Set Freezing

This example demonstrates the critical concept of 'freezing a holdout set' in machine learning projects. It shows how to split a dataset into distinct training, validation, and an isolated holdout (test) set. The holdout set remains untouched during model training and hyperparameter tuning, ensuring an unbiased final evaluation of the model's generalization ability.

## Language

`python`

## How to Run

1. Ensure Python 3 and pip are installed.
2. Install required libraries: `pip install scikit-learn numpy`
3. Run the script: `python main.py`
